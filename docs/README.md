# docs

The Syncademy site's design documents (calendar, setups, bookkeeping, after the raid, study feats, the public site,
the platform and every decision) live in `docs/` on the branch `claude/setups-mvp-712822`, next to the code they
describe, until that branch is merged into `main`. Start with `docs/README.md` there. Write changes to them there, not
here.

They used to be split between the two branches. `SETUPS_CONCEPT.md` and `STUDY_FEATS_CONCEPT.md`, which were here,
became `overview.md`, `decisions.md`, `study-feats.md` and the other documents there on 31 October 2026; that
`docs/README.md` maps where each earlier section went.

`ACCESS_CONCEPT.md` stays here: it describes the scorecard as `main` publishes it to GitHub Pages. Its current version,
for the site on syncademy.net, is `docs/access.md` on the branch.
